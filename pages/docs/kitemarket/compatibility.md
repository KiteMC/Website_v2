CoinsEngine 与 ExcellentEconomy 在部分发行版的官方要求中明确不支持 Folia。市场支持某个平台不代表所有充提后端也支持它。可让玩家到同版本、已认证的 Paper 网关节点充提；具体行为见[钱包文档](./wallet)。

跨版本代理或协议翻译插件不会改变物品存储契约。客户端可以如何连接由网络自行决定；**共享同一市场的服务器节点必须使用相同 Minecraft 版本**。

当前 IA 证据限于下列代表组合，不认证 Folia、Legacy、1.20.5 或 26.x。未验证或资源未就绪的节点保留完整原版 GUI；主题可用性不会阻止基础交易或资产退出，也不限制第三方自行开发和验证其他主题。保留原版与IA兼容，不扩大版本矩阵、不重跑未改动的金融事务。官方 Market Stall DLC 开发与上架已取消，不再与插件同步发布；萌芽／龙核接入也不再是发布门槛。见[界面与第三方开发](./ui-development)及[ItemsAdder 接入与回退](./dlc)。

## 认证记录需要包含什么

记录服务器核心与构建号、Java、KiteMarket 构建、数据库版本、经济插件及币种设置，并验证三种交易、并发、充提、领取、重启恢复和授权退出。成功编译或启动不能替代这些验证。

下载页只从实际公开 Release 识别固定文件名，不自动选择第一份 JAR。运行包开放后按 SHA-256 确认准确构件；API、sources 与 Javadoc 不作为服务器插件。

## 分发范围与历史证据

| 分发 | 版本范围 | 插件字节码 |
|---|---|---|
| Legacy | 1.16.5–1.20.4 | Java 11 |
| Modern | 1.20.5–1.21.11 | Java 21 |
| Current | 首发目标 26.2 | Java 25 |

插件字节码不是核心运行 Java 要求。服务器仍需使用该核心要求的 JVM；不能因为 Legacy 是 Java 11 字节码就用 Java 11 启动所有旧版核心。

基础版本范围保留；此前逐版本验证计划已取消。本轮围绕实际改动使用一个代表环境，保留各旧报告的准确构件和场景，不把未验证组合写成认证，也不将旧启动记录升级为完整交易认证。

2026-10-01 的开发测试已在 Paper 1.21.11 build 132、Java 21 的两节点上完成普通一口价购买/领取、部分收购供货/撤单退款、公开竞拍/延时/结算，以及真实客户端的一组高级条件流程。PlayerPoints 3.3.5 的正常充值和提现也有实际余额证据。这些结果只覆盖指定开发环境，不代替完整故障恢复、特殊物品、Purpur、Folia 或其他版本认证。

2026-10-02 另有以下**仅启动验证**：Paper 1.16.5 build 794（Temurin 16）、Folia 1.21.11 build 14（Java 21）和 Paper 26.2 build 129（Java 25）。三者均实际加载对应开发包、连接 MariaDB、执行诊断并正常关闭；没有玩家交易、物品保真或外部经济认证。26.2 服务端有 Windows 性能计数器环境异常，KiteMarket 的启动和诊断仍实际完成。
